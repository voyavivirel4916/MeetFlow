# T14 排期、参与者与时段模型

日期：2026-10-27。对应MF-03、MF-04和DT-05～07，沿用12号设计。此阶段只建立数据库结构，不开放排期接口或编辑页。

## 本轮结构

新增迁移 `0002_poll_structure`，父版本为 `0001_core`；旧迁移保持不变，升级仅增加三张表和索引。

| 表 | 关键规则 |
| --- | --- |
| polls | 所属小组外键；标题1～100、说明≤10000、地点≤200；说明/地点默认空，状态默认DRAFT，仅允许设计中的五种状态；截止及创建/更新时间存UTC毫秒整数；UNIQUE(id,group_id)，索引(group_id,status) |
| participants | PK(poll_id,user_id)；importance为REQUIRED/NORMAL；submitted_at可空。复合外键同时约束排期所属组与用户成员关系，不能跨组挂接参与者 |
| slots | 正整数主键、所属排期外键；开始/结束为整数且start_at<end_at；同排期同起止不重复，保留UNIQUE(poll_id,id)供后续答案/会议引用 |

外键删除默认RESTRICT，不级联清空业务记录；草稿替换允许服务在事务中显式移除尚无后续引用的参与者与时段。数据库允许空参与者/时段的草稿，也允许候选时段部分重叠，不增加“所有候选必须互不重叠”的规则。

五种状态值可以落库，不代表状态流转已经实现。参与者人数、1～15时段、未来截止且早于所有候选开始、发布后冻结等业务规则由T15服务事务校验；投票表留到T17，未提前添加会议或任务表。
