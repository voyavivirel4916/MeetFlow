# T11 认证与会话边界测试

日期：2026-10-26。对应MF-01、MF-13和AC-01，补充T09已有的认证测试。无新增接口、表结构或依赖。

## 新增检查

`Src/backend/tests/test_auth_boundaries.py` 新增9项测试，使用临时SQLite库、独立HTTP客户端和真实事务。

| 场景 | 验证结果 |
| --- | --- |
| 并发注册相同规范化用户名/邮箱（2项） | 一个201、一个409，只保留一条账户记录，不产生会话 |
| 两个独立客户端并发登录 | 两个令牌均有效；退出其中一个不会影响另一个 |
| 同令牌并发退出 | 两次200；原到期时间之后重复退出仍200，首次撤销时间不变；旧令牌不能查询本人 |
| 登录轮换与旧令牌退出并发 | 原会话失效，新会话有效，不会误撤销新登录 |
| 注册/登录/退出提交失败（3项） | 在已执行写入、尚未提交时注入异常；返回503、不改Cookie；注册记录、会话插入和撤销全部回滚，恢复后手动操作可成功 |
| 退出等待写锁期间跨过到期时间 | 取得锁后重新检查时间，返回401，不把过期会话写成成功退出 |

并发测试使用屏障同时发起请求，检查最终数据库记录；写锁测试用事件定位等待点并推进可控时钟，不依赖固定休眠。提交故障测试确认事务内写入已经发生，再触发失败并检查回滚后的数据。
