# T21 推荐评分、排序与解释

日期：2026-10-27。对应MF-08、API-07推荐部分及IN-04。规则集中在`app/recommendations/core.py`，独立纯函数不访问数据库、网络或时钟，不修改输入；没有新迁移或依赖。

- 得分沿用需求第5节：必到权重3、普通1；有空2、勉强1、没空-2；未填基础0且每人扣2；必到没空每人额外扣20。
- 排序固定为必到没空人数升序、最终分降序、有空人数降序、开始时间升序、结束时间升序、候选ID升序。冲突用户ID按升序返回，输入乱序不改变结果或解释。
- 返回基础分、最终分、四态人数、必到没空/未填/勉强人数、全部没空成员ID和服务端解释。必到未填提示尚未确定，勉强提示需协调；所有时段均有没空成员时明确警告，不自动确认会议。
- `GET /api/v1/polls/{poll_id}/recommendations`仅从同一授权矩阵快照计算，不缓存、不落库。组内非参与者也可读；组外404、匿名401；草稿/取消409，OPEN/CLOSED/CONFIRMED可读。客户端参数不能替代得分。
- 非法或重复参与者/时段/答案、跨排期答案、无候选或超出20×15的纯函数输入均拒绝；未填允许显式null或缺少对应答案。

验证：新增30项评分与接口测试，后端449项完整回归通过；需求原始算例排名T1/T3/T2、得分8/7/-16。真实浏览器验证得分、未知警告、冲突ID、状态、关闭回看与成员/组外/匿名权限。全部测试使用独立临时库。

复现：`Src/backend`下执行`.venv/Scripts/python.exe -m pytest tests/test_recommendations.py -q`；`Src/frontend`下按既有浏览器环境执行`node browser.check.mjs --built --polls`。T22继续补充样本边界，T23再接可见推荐列表。
