# T15 草稿与排期状态接口

日期：2026-10-27。对应MF-03～05、API-04/05及AC-03/04。使用T14的0002结构，无新增迁移或依赖；排期编辑页面留T16。

## 已实现接口

以下路径以 `/api/v1` 开头，需要有效会话、统一响应封套，响应不缓存。排期组外与不存在均返回相同404；组内普通成员可读，写操作仅负责人允许，权限不足403。

| 请求 | 行为 |
| --- | --- |
| POST /groups/{g}/polls | 创建DraftIn，成功201；空参与者/时段数组可存草稿，不自动发布 |
| PUT /polls/{p} | 仅DRAFT可整体替换基本信息、参与者、时段；同一事务保存，失败恢复完整旧稿 |
| GET /polls/{p} | 返回PollOut：基础信息、实际/有效状态、参与者摘要、时段和更新时间；不返回邮箱 |
| GET /groups/{g}/polls | 本组分页PollOut，默认page=1/page_size=20、上限50；created_at、id倒序；参与者/时段按整页批量读取 |
| POST /polls/{p}/open | `{}`，仅DRAFT发布；至少1参与者、1～15时段，截止须在未来且早于每个候选开始，否则422 |
| POST /polls/{p}/close | `{}`，OPEN→CLOSED；重复CLOSED返回原记录，不改变更新时间 |
| POST /polls/{p}/cancel | `{}`，DRAFT/OPEN/CLOSED→CANCELLED；重复取消返回原记录；CONFIRMED不可取消 |

输入拒绝未知字段，负责人、状态、slot ID和提交时间不能由前端伪造。标题trim后1～100字符，说明≤10000、地点≤200；时段必须开始早于结束，不允许规范化后重复，参与者须为当前组成员且不重复。草稿暂存可为空，1～15时段限制在发布时检查；候选允许部分重叠。发布后整体结构冻结，禁止重开终态。

时间输入必须是带时区RFC3339字符串，拒绝无时区及数字时间；转换为UTC毫秒存储，额外小数精度截取到毫秒，随后检查时段顺序/重复。输出为UTC、Z后缀、三位毫秒，跨日转换保持同一时刻。

## 截止与事务

GET返回实际status及effective_status。达到截止（含恰好相等）时，OPEN的有效状态为CLOSED；读取不写库，也不改updated_at。负责人下一次有效写请求在取得写锁、重新检查权限后计算时间，先落库到期关闭。即使随后发布/替换因状态返回409，该关闭仍提交，草稿内容不改；存储故障则整个事务回滚。非法正文或无权限请求不触发业务状态写入。

仅DRAFT允许发布，重复open返回409；close/cancel按上表幂等。发布与保存共用SQLite短写事务，并发时先取得锁者完成，后续请求重新检查状态，不能在发布后改写结构。DB_BUSY/存储失败返回503，不自动重发写请求。列表读取采用一致快照。

## 实际验证

- 后端358项通过（本轮新增87项）；前端116项、构建和32项仓库检查通过。
- 覆盖全部15组状态/动作组合、字段边界、重复/倒置时段、跨组参与者、16时段发布拒绝、发布后编辑、截止前/等于/后边界、时区及毫秒、分页和批量查询。
- 验证写锁等待后重新判断截止、读取中跨截止不误判、到期写入后409仍持久关闭、子记录插入/最终提交失败回滚、写锁繁忙恢复，以及并发发布与替换不破坏冻结结构。
- Chrome、Edge正式构建和Chrome开发代理使用三个独立真实浏览器会话验证草稿创建/替换/读取/列表、权限、发布冻结、关闭/取消幂等、终态拒绝、刷新及退出失效。故障与账号仅在临时库中，不写开发数据。
