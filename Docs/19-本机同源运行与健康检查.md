# T08 本机同源运行与健康检查

日期：2026-10-26。沿用现有需求与设计，不扩展首版范围。

## 完成内容

前端构建后，由FastAPI在同一地址提供页面、`/assets`和`/api/v1`。本机运行无需持续启动Vite，也不访问外网。页面深链接可直接打开、刷新，未知页面由Vue显示未找到；未知API、缺失资源和保留路径返回JSON错误，不被SPA入口覆盖。

启动检查数据目录与数据库写权限、迁移版本及基础表，以及前端入口和入口引用资源。缺库、版本不符、只读或损坏库、缺少构建文件时终止启动；命令行提示不输出配置值和堆栈。数据库仍须显式迁移，不在启动中自动建表、修复或导入账号。

| 接口 | 含义 |
| --- | --- |
| GET /livez | 进程存活，与数据库状态独立 |
| GET /api/v1/health | 无需登录；数据库可读且版本正确时返回`{data:{status:"ok"},request_id}`；异常时503、`STORAGE_UNAVAILABLE` |

健康接口只读、不缓存，不返回路径、版本号或用户数据；连接检查页面已改为调用该接口。启动写权限探测在事务内执行并回滚，经验证不改变已有数据库内容。

## 复现方式

按[后端README](../Src/backend/README.md)先执行前端`npm ci`、`npm run build`，再安装后端依赖、运行`python -m app.db.migrate`、`python -m app`。访问[本机页面](http://127.0.0.1:8000/)或[连接检查](http://127.0.0.1:8000/connection)。首次安装需要下载依赖，构建后的应用运行不需要外网。

开发仍可使用5173端口的Vite代理；单服务构建检查使用前端目录的`npm run check:delivery`，具体环境与命令见[前端README](../Src/frontend/README.md)。
