# T26 议程与纪要接口

日期：2026-10-27。对应MF-10、API-09，无新迁移或依赖。

组成员可通过`GET /api/v1/meetings/{m}`读取会议详情，通过`GET /api/v1/groups/{g}/meetings?page=1&page_size=20`分页查询；按开始时间、会议ID倒序，页大小1～50，空组返回空列表。总数和当页内容在同一只读事务中读取。

负责人使用`PATCH /api/v1/meetings/{m}`保存`agenda`、`minutes`，至少提供一项。每项最多10000个Unicode字符，允许空字符串清空，保留换行和空格；拒绝null、非法字符及其他字段，不修改来源、标题、地点、时间或选择理由。部分更新只修改提供的字段，两项同时保存共同提交。重复相同内容不改变更新时间。

成员写入403，跨组及不存在的会议404，未登录401。所有响应不缓存；存储失败回滚，不报告假成功。这里没有新增会议状态、记录人权限或富文本功能。

验证：后端全量535项通过，其中本项新增19项。覆盖部分修改/清空、纯文本及Unicode长度、字段冻结、角色与跨组权限、分页及极大页码、写入/提交失败回滚、并发修改不同字段不互相覆盖。原有会议确认、推荐与投票测试全部通过。

复现：在`Src/backend`运行`.venv/Scripts/python.exe -m pytest -q`。已有0004数据库无需升级，更新代码后重启后端服务。
