# T24 会议确认事务与去重

日期：2026-10-27。对应MF-09、API-08、DT-09。

负责人结束收集后，调用`POST /api/v1/polls/{p}/confirm`选择候选。写事务取得锁后复查权限、有效状态和候选归属，使用同一数据库快照重新计算排名。必到没空、必到未填或选择非首位时，必须确认风险并填写1～500字理由；必到勉强只提示协调。首次返回201，同候选重试返回原会议和200，不覆盖原理由；改选其他候选返回409。

`0004_meetings`新增会议表、排期唯一约束和来源复合外键。会议快照插入与排期CONFIRMED状态共同提交，失败共同回滚。数据库唯一约束作为去重兜底，只处理目标唯一冲突，不掩盖其他完整性错误。

为响应丢失后的核对补充`GET /api/v1/polls/{p}/meeting`：组成员可读，尚未确认返回null；不触发写入。完整会议详情、列表、议程和纪要留在T26。

验证：后端全量516项通过。覆盖权限与非法输入、同候选/异候选重试、并发确认/取消、截止边界、数据库忙、写入及提交失败回滚、唯一冲突恢复、其他约束错误、旧库升级及迁移失败回滚。

本机数据库已备份再升级，升级前后原有表数据一致，外键检查通过。其他已有库须先备份，再运行后端迁移命令并重启服务；无新增依赖。浏览器验证使用独立临时库，不写入实际会议样本。
