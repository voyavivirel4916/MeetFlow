## 5. 每阶段结束时

核对关联需求 → 执行相关测试与人工复核 → 记录实际结果及未完成项 → 更新受影响文档 → 创建Git提交 → 运行双平台同步并核对版本。阶段报告简述完成项、证据和下一项任务即可，不需要重复复制长篇Agent提示词。
