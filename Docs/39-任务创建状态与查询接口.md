# T28 任务创建、状态与查询接口

日期：2026-10-27。对应MF-11、MF-12、API-10/11。新增`0005_tasks`，已有库须先备份再迁移、重启服务。

负责人在已确认会议下创建任务，提供标题、可选说明、组内执行人、未来截止和UUID创建标识。取得写锁后校验截止；首次201。同一创建人、同一标识、相同规范化输入重试返回原任务和200，即使截止已过也不会重复生成；改变输入或换会议复用标识返回409。数据库唯一约束和写事务共同保证去重。

负责人或执行人可切换待开始、进行中、已完成三态。完成时记录时间，重开时清空；重复相同状态不改变原完成时间。其他组员只能查看，跨组隐藏为404。任务输入不接受额外状态、非法执行人或超长/无效文字。

小组任务和个人待办查询同一张表，按截止时间、ID升序分页。小组默认全部状态，个人默认排除已完成；可显式筛选三态。小组查询补充可选`meeting_id`，会议页只读取当前会议任务，分页总数仍准确，不在前端过滤一页小组数据。

任务表通过复合外键保证会议与小组、执行人与小组一致，约束截止晚于创建时间及完成时间与状态一致；为既有会议添加来源复合唯一索引。新增两项任务查询索引，无新依赖。

验证：后端全量572项通过，其中本项新增37项。覆盖规范化重试、截止前后、非法输入、执行权限、状态重开、默认待办/完成筛选、会议归属及分页、并发唯一、写入与提交失败回滚、表约束、旧库增量升级与失败回滚。

本机库已备份再升级，原有九张表数据逐项核对一致，外键检查通过，任务表初始为空。浏览器演示样本使用独立临时库。
