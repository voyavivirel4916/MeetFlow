# T09 认证与会话接口记录

日期：2026-10-26。对应MF-01、MF-13及API-01，沿用本机桌面第一版；本轮实现后端认证，页面与路由守卫留在T10。

## 已完成的接口

以下路径均以 `/api/v1` 开头，响应使用既有data/error与request_id封套，认证响应不缓存。

| 请求 | 输入/结果 |
| --- | --- |
| POST /auth/register | `{username,email,password}`；成功201，返回本人`{id,username,email}`；重复账号409；不自动登录 |
| POST /auth/login | `{username,password}`；成功200，返回本人信息并设置会话Cookie；账号不存在与密码错误统一401 |
| GET /users/me | Cookie会话有效时返回本人信息；缺失、未知、撤销或到期会话返回401 |
| POST /auth/logout | 正文`{}`；撤销当前会话后200并删除Cookie；已撤销令牌再次退出仍200；缺失、未知及未撤销但已过期的令牌返回401 |

用户名trim后转小写，注册限3～32位ASCII字母、数字、下划线；邮箱trim并转小写，使用标准邮箱校验依赖，不查询DNS、不验证实际收信能力。注册密码8～128字符、非纯空白；不trim密码，首尾空格有意义；未知输入字段拒绝。

## 存储与会话规则

密码使用Python标准库scrypt，沿用设计参数N=16384、r=8、p=1，随机16字节盐，64字节派生值；保存算法、参数、盐和派生值，校验用常量时间比较。未知账号仍走一次密码哈希验证路径，不直接提前返回。

每次成功登录产生32随机字节令牌，Cookie名 `meetflow_session`，数据库仅存其SHA-256摘要；不使用JWT或可复用默认密钥。有效期固定8小时，无自动续期。Cookie为HttpOnly、SameSite=Strict、Path=/、Max-Age=28800、无Domain；本机HTTP按设计不设置Secure。

成功登录在同一事务中创建新会话并撤销当前浏览器原令牌，其他浏览器会话保留。失败登录不影响已有会话。退出提交撤销成功后才删除Cookie；写锁超时或存储失败返回503，不返回假成功。认证在读取记录后检查时钟，避免数据库等待期间跨过到期时间仍被放行。

表结构沿用T07的0001_core，无新增迁移。`auth/dependencies.py`提供可供后续小组等模块复用的当前用户依赖；本轮尚不实现小组权限。日志增加经服务端验证的用户ID，不记录邮箱、正文、密码、Cookie或令牌。

API拒绝跨来源Origin和非同源Fetch来源；写请求要求application/json，正文上限256KiB，实际流式内容也受限。无浏览器来源头的本机命令行客户端仍可使用，不开放跨域访问权限。
