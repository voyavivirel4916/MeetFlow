# MeetFlow 第一版思维导图

整理基线：B1｜2026-10-25。此图表示当前第一版范围，不回写立项会议当时的讨论内容。

![MeetFlow第一版思维导图](images/MeetFlow-思维导图.png)

## 节点内容

### 用户与权限

- 负责人：排期、确认、纪要、指派
- 普通成员：本人填写、任务进度
- 组内可见，服务端验证对象归属

### 排期与推荐

- 候选时间、必到成员、三态填写
- 发布后冻结，截止后禁止提交
- 时间矩阵、稳定排序、冲突解释

### 会议与任务

- 唯一确认、风险警告与选择理由
- 纯文本议程与纪要
- 任务列表、执行人、截止与三态

### 本地运行与验收

- Vue + FastAPI + SQLite
- 桌面单实例，20人、15时段
- 四账号闭环、权限、并发与恢复

### 两人协作

- 马若曦：统筹、主要开发、集成
- 陈明强：填写页、结果页、汇报
- 36项任务，验证后提交并双端同步

### 边界与后续

- P1可选：本人首页汇总
- 公开部署与真实反馈：后续交付
- 手机、统计图、提醒、看板：不纳入
