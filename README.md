## 项目简介

课程小组、社团和学生团队经常需要通过群聊反复询问成员空闲时间。信息分散、必到成员与普通成员的重要程度不同，最终结果也缺少清晰依据。即使会议时间确定，会议纪要和会后任务往往又分散在其他工具中。

MeetFlow 提供“创建排期—成员填写—智能推荐—确认会议—记录纪要—跟踪任务”的完整协作闭环。系统重点解决多人时间协调效率低、推荐结果不可解释以及会议决定难以持续跟踪的问题。

## 核心流程

```text
创建小组 → 发起排期 → 设置候选时间 → 成员填写空闲状态
→ 系统生成推荐结果 → 发起人确认会议 → 记录纪要 → 分配并跟踪任务
```

## 核心特色

- 区分必到成员与普通成员，避免简单多数投票忽略关键参与者；
- 使用可解释的排期评分规则，展示推荐理由和冲突成员；
- 用时间矩阵、提交进度和推荐列表展示多人时间分布；
- 将时间协调、会议纪要和任务跟踪连接为完整闭环；
- 不依赖校园内部接口或付费第三方服务，便于稳定演示与发布。

## 第一版范围与技术方向

第一版采用本地单实例、桌面浏览器、SQLite，每组最多20人、每次1～15个候选时段。支持账号、小组、三态填写、可解释推荐、会议确认、纯文本纪要、任务列表和个人待办；负责人和普通成员两种小组角色。

- 前端：Vue 3、TypeScript、Vite及基础组件库，界面以表单、矩阵和列表为主。
- 后端：Python、FastAPI、SQLAlchemy、可撤销服务端会话；依赖版本在脚手架阶段锁定。
- 测试：Pytest、Vitest与人工验收；已有文档检查使用Python标准库。
- 版本管理：Git，同一提交同步至Gitee、GitHub。

公网发布另列后续课程交付，手机适配、统计图、提醒和复杂任务管理不进入本地第一版。完整范围见下表。
