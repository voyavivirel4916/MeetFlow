# MeetFlow T02 交互原型

日期：2026-10-26。需求依据：[03 第一版范围](../../Docs/03-需求边界与MVP.md)、[09 需求分析V1.2](../../Docs/09-需求分析文档.md)、[12 系统设计V1.0](../../Docs/12-系统设计文档.md)。

当前原型P0.3采用方向A“时间拼图”。先查看填写页的候选时间卡片、推荐页的成员拼图矩阵与推荐卡；可在上方场景中选择“已填写的排期”或“必到成员未填写”快速体验。共享配色及拼块样式在`puzzle.css`，业务演示规则仍在`model.mjs`。

本原型用于讨论操作流程、文案和页面布局。它使用HTML/CSS/JavaScript模块与浏览器本地存储，没有真实登录、服务端权限或数据库，不代表后续Vue/FastAPI业务实现已经完成。

## 打开方式

在仓库根目录运行：

```powershell
python Src/scripts/preview_prototype.py
```

浏览器会打开 [本机原型](http://127.0.0.1:8765/)。保持启动窗口打开，结束时按Ctrl+C。若端口被占用，可增加 `--port 8766`；不自动打开浏览器可增加 `--no-browser`。不要直接双击index.html，浏览器通过HTTP加载模块。

本机地址只在启动服务的这台电脑上有效；其他人可从仓库下载后按同样命令预览。需要交给老师的共享原型地址时，可后续将这个静态目录放到约定的原型分享平台，不将它作为真实业务系统部署。

## 建议体验顺序

1. 从“我的小组”进入“发起排期”，设置主题、截止时间、候选时段、参与者与必到成员，发布收集。
2. 在“填写时间”逐项选择有空、勉强或没空。漏填会提示；勾选“一次保存失败”可检查输入保留，再重试。
3. 切换上方四个模拟账号，分别填写完整答案。林同学、周同学仅为演示参与者，开发成员仍为马若曦和陈明强。
4. 切回马若曦，查看时间矩阵与推荐，关闭收集后选择时段。必到没空、必到未填或非首选时段需风险确认与理由。
5. 进入会议，保存纯文本议程和纪要，创建两项带执行人、截止时间的任务。
6. 切换执行人，在“我的待办”更新任务。完成项默认隐藏；勾选“包含已完成”可重开，会议任务同步显示。

上方场景选择器还可直接载入“已填写的排期”“必到成员未填写”“所有时段有冲突”。载入场景会替换当前演示数据；重置演示会回到初始草稿。刷新可保留已保存数据；未保存输入离开时提示。

原型采用桌面布局，最低检查视口为1280×720。日期以打开时的日期生成未来候选，展示北京时间；截图日期是验证当天的演示数据。演示时请使用北京时间的系统设置。

P0.2额外检查桌面窗口缩小到1024、800与640×520的情况：窄窗口改为单列，侧栏在更窄时显示图标，悬停可见导航名称。该检查用于防止窗口移动时的遮挡，不扩展为手机验收。

## 页面与需求追踪

| 原型入口 | 操作重点 | 需求/设计 |
| --- | --- | --- |
| `#group` 我的小组 | 已有小组与演示参与者，进入排期 | UI-02；建组、入组和认证在业务实现阶段完成 |
| `#draft` 发起排期 | 草稿、成员、必到、候选及发布 | MF-03/04/05；UI-03 |
| `#vote` 填写时间 | 完整三态答案、覆盖本人、失败保留 | MF-06；UI-04 |
| `#results` 时间与推荐 | 矩阵、分数组成、未知/冲突、关闭与风险确认 | MF-07/08/09；UI-05 |
| `#meeting` 会议与任务 | 唯一会议、只读/编辑纪要、任务创建和状态 | MF-10/11；UI-06 |
| `#tasks` 我的待办 | 执行人过滤、完成和重开 | MF-12；UI-07 |

负责人/成员差异为交互演示。真实的身份、小组隔离、并发事务及截止检查仍须后端实现和独立验证。原型中的评分函数用于核对展示，不替代T21的后端算法交付。没有增加P1首页、统计图、提醒或拖拽看板。

## 验证与截图

无需安装依赖即可运行规则测试（需Node.js）：

```powershell
node --test Src/prototype/model.test.mjs
```

浏览器验证另需Playwright与本机Chrome或Edge。已有Playwright时，指定其包目录即可，不要求更改项目业务依赖：

```powershell
$env:PLAYWRIGHT_MODULE_PATH = '你的Playwright包目录'
node Src/prototype/browser.check.mjs
# 使用Edge
$env:PROTOTYPE_BROWSER = 'msedge'
node Src/prototype/browser.check.mjs
```

验证脚本启动自己的临时本机服务，逐步操作页面并核对结果；加 `--screenshots` 更新截图。仅在明确需要更新证据时使用该选项。截图和本轮结果见[原型交付记录](../../Docs/14-交互原型与验证记录.md)。
